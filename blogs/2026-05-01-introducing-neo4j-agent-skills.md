<div><img alt="" class="attachment-large size-large wp-post-image" height="498" src="https://dist.neo4j.com/wp-content/uploads/20260430192621/1DWgg4VX6iJeZiEe_OxEzrQ.png" style="margin-bottom: 15px;" width="640" /></div><h2>Teaching agents the latest Cypher and Neo4j&nbsp;patterns</h2><p>Did you know that in Cypher 25 you can write&nbsp;this?</p><pre class="code CodeMirror cm-s-paraiso-dark">CYPHER 25 MATCH REPEATABLE ELEMENTS p = SHORTEST 3<br />  (alice:Person {name: "Alice"})<br />  (()-[r:KNOWS]-() WHERE r.since &gt; date("2020-01-01")){1,5}<br />  (bob:Person {name: "Bob"})<br />RETURN [n IN nodes(p) | n.name] AS chain,<br />       length(p) AS hops<br />ORDER BY hops</pre><p>Neither did I or probably the LLM you&rsquo;re&nbsp;using.</p><p>That single MATCH packs in SHORTEST 3 to ask for the three shortest paths, walking a <code>REPEATABLE ELEMENTS</code> trail, a quantified path pattern with an inline predicate on the relationship, and a path projection in the RETURN. Most of it landed as part of the GQL alignment in Cypher 25, and your coding agent has not seen any of&nbsp;it.</p><p>Claude Code, Cursor, Codex, whichever one you use, will not reach for this syntax because it did not exist when the model was trained. Agents are otherwise very capable at Cypher. They reason about query shape, they pick up your schema quickly, they know the rough surface area of the language. The thing they cannot do is keep up with it. Cypher has moved on a lot in the last two years, GQL alignment has reshaped the surface in non-trivial ways, and the model has no way of knowing what it does not&nbsp;know.</p><p>Agent Skills are a nice way of handling exactly this, and there is now a first wave of them for&nbsp;Neo4j.</p><p><a href="https://github.com/neo4j-contrib/neo4j-skills" rel="noopener nofollow" target="_blank">GitHub &#8211; neo4j-contrib/neo4j-skills: Neo4j Skills for Coding and other Agents including Cypher</a></p><h3><strong>What is an Agent&nbsp;Skill</strong></h3><p>A skill is a folder with a SKILL.md at the root, fronted by a short description the agent always sees. The body of SKILL.md loads only when the agent matches the task to the skill. Deeper material in references/ loads only when SKILL.md asks for&nbsp;it.</p><figure><img alt="" src="https://dist.neo4j.com/wp-content/uploads/20260430192621/1DWgg4VX6iJeZiEe_OxEzrQ.png" /><figcaption>Agent skill&nbsp;design</figcaption></figure><p>Progressive disclosure is the trick that lets you encode a lot of opinionated guidance without burning&nbsp;context.</p><h3>What is in the&nbsp;repo</h3><p>The Neo4j skills live at <a href="https://github.com/neo4j-contrib/neo4j-skills" rel="noopener nofollow" target="_blank">neo4j-contrib/neo4j-skills</a>. The repo is community driven, MIT licensed, and the skills are grouped into a few categories so you can pick what you&nbsp;need.</p><p>The <strong>Cypher</strong> skills cover the language itself: writing and optimizing queries, picking the right idioms for your version, and steering the agent away from deprecated syntax.</p><p>The <strong>driver</strong> skills are split per language, one each for Python, JavaScript, Java,&nbsp;.NET and Go, plus a migration skill for upgrades.</p><p>Around those sit categories for <strong>importing data</strong>, <strong>AI and search</strong> (vector indexes, GraphRAG, agent memory, the Neo4j MCP server), <strong>Graph Data Science</strong>, and <strong>frameworks and platforms</strong> like GraphQL, Spring Data, the Aura CLI and the various admin&nbsp;tools.</p><p>You can install the whole bundle and let the agent pick what it needs, or pull in only the few that match your stack. We also have them listed on <a href="https://skills.sh/neo4j-contrib/neo4j-skills" rel="noopener nofollow" target="_blank">skills.sh</a> so that they are discoverable with find-skill&nbsp;.</p><p><a href="https://skills.sh/neo4j-contrib/neo4j-skills" rel="noopener nofollow" target="_blank">Skill for neo4j-contrib/neo4j-skills</a></p><p>There is plenty of room to grow on top of this, and contributions are&nbsp;welcome.</p><p>We keep them up to date by running a regular headless Claude Code GitHub action that reviews latest release notes, changelog, and docs changes and creates a PR with proposed updates. The repository has also a skill writing skill in AGENTS.md that we apply as part of&nbsp;that.</p><h3>A worked&nbsp;example</h3><p>Say you are wiring up a friend recommendation feature and you want the agent to write the query and the Python around it. With the Cypher skill and the Python driver skill loaded, the agent has both halves: how to express the traversal, and how to run it from the&nbsp;driver.</p><pre class="code CodeMirror cm-s-paraiso-dark"># Install all Neo4j skills at once<br />npx skills add neo4j-contrib/neo4j-skills<br /><br /># Or just the two relevant for this example<br />npx skills add neo4j-contrib/neo4j-skills/neo4j-cypher-skill<br />npx skills add neo4j-contrib/neo4j-skills/neo4j-driver-python-skill</pre><p>The skills CLI auto-detects your agent (Claude Code, Cursor, Cline, Gemini CLI, Codex) and drops the files in the right place. Once the skills are in, no extra ceremony. You just describe the&nbsp;task.</p><p>Alternatively you can install the repo as a plugin in Claude Code, Codex or Gemini&nbsp;CLI.</p><h3>Help build the next&nbsp;wave</h3><p>The promise here is simple and powerful. The model does not need to be retrained. You just put the right knowledge next to the right task and the agent reaches for it. Give the Neo4j agent skills a spin on a real project and let us know how they land. What works, what misses, where the agent still goes off the rails, which corners of Neo4j deserve a skill of their&nbsp;own.</p><p><em>The repo issues are the fastest way to feed that back, and it is what the next wave gets built&nbsp;on..</em></p><p><a href="https://github.com/neo4j-contrib/neo4j-skills" rel="noopener nofollow" target="_blank">GitHub &#8211; neo4j-contrib/neo4j-skills: Neo4j Skills for Coding and other Agents including Cypher</a></p><img alt="" height="1" src="https://medium.com/_/stat?event=post.clientViewed&amp;referrerSource=full_rss&amp;postId=e69958c38dea" width="1" /><hr /><p><a href="https://medium.com/neo4j/introducing-neo4j-agent-skills-e69958c38dea" rel="noopener nofollow" target="_blank">Introducing Neo4j Agent Skills</a> was originally published in <a href="https://medium.com/neo4j" rel="noopener nofollow" target="_blank">Neo4j Developer Blog</a> on Medium, where people are continuing the conversation by highlighting and responding to this story.</p>
